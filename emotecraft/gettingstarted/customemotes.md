# Custom Emotes
This section includes information about downloading and installing emotes for emotecraft.

### Downloading
You can download emotes from [EmotecraftLibrary (RedlanceEmotes)](https://emotes.redlance.org/)

:::note
`.json` and `.emotecraft` emote files are plain data — they will NEVER contain viruses.
:::

### Installing
To install an emote, you just need to drag and drop the `.emotecraft` or `.json` file from the downloads folder into the emotes folder, which is where the `mods` folder is located

:::warning
The `.json` can also have a `.png` or `.nbs` file, so you should move those too!
:::
