# Getting Started

This section takes you from an empty project to MoLang that reads your game's state:

1. [Installation](./installation.md) — add the library and pick a module.
2. [Evaluating MoLang](./usage.md) — create an interpreter, evaluate expressions and parse them once for repeated use.
3. [Bindings](./bindings.md) — expose your own values, functions and Java classes to expressions, such as a `query` object.
